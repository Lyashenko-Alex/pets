# PetMind AI Landing Page

Static landing page prototype for an AI-powered pet health & behavior monitoring collar.

## Files
- `index.html`
- `style.css`
- `script.js`

## Run locally
Open `index.html` in a browser.

## Deploy
This is a static site and can be deployed directly to Cloudflare Pages from GitHub.

## Note
The brand name "PetMind AI" is provisional and can be replaced later.
